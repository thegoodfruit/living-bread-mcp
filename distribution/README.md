# Submission packages

Everything a directory asks for, written once, so the owner can submit in minutes from their own accounts. Nothing here
has been submitted by the builder. Status of every destination: `docs/DISTRIBUTION_TRACKER.md` (generated from
`mcp/src/data/distribution.json`, which the hub at https://mcp.living-bread.org serves live).

| File | For |
|---|---|
| `listing.md` | The shared listing: names, one line, short and long descriptions, tags, examples, logos, links. Every other file points here. |
| `smithery.md` | Smithery (URL publish) |
| `directories.md` | mcp.so, mcpservers.org, PulseMCP, Glama connectors |
| `cline-marketplace.md` | The Cline MCP Marketplace issue |
| `awesome-remote-mcp-servers.md` | The three-line entry, ready once the Glama connector exists |
| `christian-tech.md` | Bible and Christian developer lists |
| `outreach/` | Drafts only. Never sent, never implying a partnership. |

Logos: `mcp/plugin/assets/logo-512.png`, `logo-128.png`, `logo-48.png` (the dove). A 400 by 400 PNG for Cline:
`sips -z 400 400 mcp/plugin/assets/logo-512.png --out /tmp/living-bread-400.png` (macOS).
