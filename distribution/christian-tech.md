# Bible and Christian developer lists

## biblenerd/awesome-bible-developer-resources
- Sections: Formats, Biblical Corpora, APIs, Lexical Resources, Other Awesome Lists. Contributions by issue or pull request.
- Its rules (checked 2026-10-05): technical, available, functional, documented in English, useful to a broad community; neutral
  descriptions ending in a period; a license badge if known; "self-promotion is generally frowned upon and will be more critically
  scrutinized". Last commit 2025-02-27.
- Fit: the **APIs** section. Because the list scrutinises self-promotion and is quiet, the builder did NOT open a pull request;
  the honest route is an issue from the owner proposing it, letting the maintainer decide.

Proposed line:

```
- [The Living Bread MCP server](https://mcp.living-bread.org/) - Remote Model Context Protocol server, no key: KJV passages with SHA-256 evidence labels, keyword search, OpenBible.info cross references. ![MIT](https://img.shields.io/badge/license-MIT-green)
```

(That list's own format uses a hyphen between name and description; keep it as the list writes it.)

## Other places worth a human note (not submissions)
- The Christian Knowledge API (`https://discover.living-bread.org/api`, CC BY 4.0) is the JSON twin of the MCP server; any Bible
  or church data list that accepts APIs fits it better than the MCP endpoint.
- Christian technology communities (for example FaithTech) are communities, not directories: see `outreach/` for a draft post,
  to be shared by the owner if and where it is welcome.
